# GitHub Final Project

## Simple Interest Calculator

A calculator that calculates simple interest given the principal, the annual rate of interest and the time period in years.

```
Input:
   p, principal amount
   t, time period in years
   r, annual rate of interest
Output:
   simple interest = p*t*r/100
```

## Usage
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
